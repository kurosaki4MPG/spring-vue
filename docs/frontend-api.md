# Frontend API連携仕様書

## 1. 概要

- 対象: Vue 3 + Vite Frontend
- APIの呼び出し先: `/api`
- 開発時の接続: Vite proxy経由でBackendへ転送
- 認証: なし
- API共通処理: `requestJson` がHTTPエラーとJSONレスポンスを処理

## 2. 初期表示

画面表示時に、次のAPIを並行して呼び出します。

| API | 用途 | 画面反映先 |
|---|---|---|
| `GET /api/health` | Backendの稼働状態確認 | API状態 |
| `GET /api/message` | システムメッセージ取得 | システムメッセージ欄 |
| `GET /api/tasks` | タスク一覧取得 | タスク一覧・件数 |

3つのいずれかが失敗した場合、データ取得エラーを画面に表示します。

## 3. 画面操作とAPI

### 3.1 再読込

「再読込」ボタンを押下すると、初期表示と同じ3つのGET APIを再実行します。

再読込の開始時に、過去の操作通知を消去します。

- 成功通知: 非表示
- エラー通知: 非表示
- システムメッセージ: APIから再取得して表示

### 3.2 タスク追加

1. タイトルと説明を入力します。
2. 「タスクを追加」ボタンを押下します。
3. `POST /api/tasks` を呼び出します。
4. 成功時にタスク一覧を再取得します。
5. 「タスクを追加しました。」を表示します。

タイトルが空の場合はAPIを呼び出さず、画面上に入力エラーを表示します。

#### Request

```json
{
  "title": "新しいタスク",
  "description": "タスクの説明",
  "completed": false
}
```

### 3.3 タスク編集・更新

1. タスクの「編集」操作を開始します。
2. タイトル、説明、完了状態を変更します。
3. 「更新」ボタンを押下します。
4. `PUT /api/tasks/{id}` を呼び出します。
5. 成功時に編集状態を終了し、タスク一覧を再取得します。
6. 「タスクを更新しました。」を表示します。

### 3.4 完了状態の切替

タスクの完了状態を切り替えると、現在のタスク情報を使って `PUT /api/tasks/{id}` を呼び出します。

更新成功後にタスク一覧を再取得し、完了・未完了の件数を更新します。

### 3.5 タスク削除

1. 「削除」ボタンを押下します。
2. `DELETE /api/tasks/{id}` を呼び出します。
3. 成功時にタスク一覧を再取得します。
4. 「タスクを削除しました。」を表示します。

## 4. 画面状態

| 状態 | 動作 |
|---|---|
| `loading` | 初期表示・再読込中は再読込ボタンを無効化 |
| `saving` | 登録・更新・削除中は操作ボタンを無効化 |
| `error` | エラー通知を表示し、成功通知を消去 |
| `notice` | 成功通知を表示し、エラー通知を消去 |
| `message` | Backendから取得したシステムメッセージを表示 |

## 5. エラー処理

BackendがJSONエラーを返した場合は、`error` または `details[].message` を画面表示用メッセージとして利用します。

| API結果 | Frontendの動作 |
|---|---|
| `400 Bad Request` | バリデーションエラーを表示 |
| `404 Not Found` | 対象タスクが存在しない旨を表示 |
| その他のHTTPエラー | HTTPエラーまたはレスポンス本文を表示 |
| 通信失敗 | 一般的なエラーメッセージを表示 |

## 6. 対応関係

| UI機能 | HTTPメソッド | API |
|---|---|---|
| 初期表示・再読込 | GET | `/api/health`, `/api/message`, `/api/tasks` |
| タスク一覧取得 | GET | `/api/tasks` |
| タスク追加 | POST | `/api/tasks` |
| タスク更新 | PUT | `/api/tasks/{id}` |
| 完了状態切替 | PUT | `/api/tasks/{id}` |
| タスク削除 | DELETE | `/api/tasks/{id}` |
